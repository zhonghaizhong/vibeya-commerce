Example design prompt

Create a text-only print for a custom kids basketball jersey and shorts set. Keep the jersey and shorts solid red; place the print directly on the fabric with no background box, panel, stripes, illustrations, or extra graphics. Jersey front: large BASKETBALL, smaller NEVER STOP beneath it, and a bold number 23 below. Jersey back: MILO above a large 23. Shorts: a matching 23. Use warm ivory lettering with a deep navy outline and a very thin muted champagne accent in a clean varsity athletic type style. Keep each print centered and readable.
