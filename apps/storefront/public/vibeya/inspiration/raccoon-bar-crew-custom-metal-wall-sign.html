Example design prompt

Example design prompt
Create an original funny three-piece custom metal wall sign set for a home bar. Design three coordinated circular illustrations with a vintage cartoon raccoon bar crew: the first raccoon offers a foamy root beer mug, the center raccoon plays bartender and reaches toward both sides, and the third raccoon holds a mug while sneaking a pretzel. Use a deep teal background, warm cream, rust orange, mustard, bold clean outlines, and a black scalloped bottle-cap edge. Keep each character readable within its own round sign, connect the set with a shared bar-counter motif, and do not add text, logos, or existing characters.
