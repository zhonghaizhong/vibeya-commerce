# VIBEYA Commerce

VIBEYA is a self-expression-first customizable apparel storefront prototype. The site currently uses VIBEYA branding and preserves its lavender, pink, cream and lime visual identity.

## Preview and hosting

Open `index.html` locally or publish the repository through GitHub Pages (`Settings → Pages → Deploy from a branch → main → /(root)`). Relative links support the project URL `https://zhonghaizhong.github.io/vibeya-commerce/`.

## Status

This is an interactive prototype, **not a live checkout**. Payment, order submission and Medusa backend integrations are not connected. Do not accept real payments or expose customer data until production services are integrated and tested.
